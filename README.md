## 🚀 Getting Started

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project folder

```bash
cd HTML-CSS-Layout
```

Open the project in your preferred code editor (VS Code recommended) and run the HTML files directly in your browser or using the Live Server extension.
