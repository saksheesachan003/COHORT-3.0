## 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the Assignments folder:

```bash
cd Assignments
```

Install dependencies (if required):

```bash
npm install
```

Run the project:

```bash
npm run dev
```

or

```bash
npm start
```
