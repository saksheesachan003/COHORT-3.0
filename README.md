## 🚀 Getting Started

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the JavaScript folder

```bash
cd JavaScript
```

Open the project in your preferred code editor.

To run JavaScript files:

```bash
node filename.js
```

Or simply open the HTML file in your browser for DOM-based projects.
